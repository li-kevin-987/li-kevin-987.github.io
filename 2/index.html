Part 1.1: Convolutions from scratch

Convolution with 4 loops

I implemented convolution with 4 loops as follows:

def convolve4loops(image, kernel):
  kernel = np.flip(kernel)
  pad_1 = kernel.shape[0] // 2
  pad_2 = kernel.shape[1] // 2
  image_x = image.shape[0]
  image_y = image.shape[1]

  image = np.pad(image, ((pad_1,pad_1), (pad_2,pad_2)))

  out_image = np.zeros((image_x, image_y))

  for ix in range(image_x):
    for iy in range(image_y):
      for kx in range(kernel.shape[0]):
        for ky in range(kernel.shape[1]):
          out_image[ix][iy] += kernel[kx][ky] * image[ix + kx][iy + ky]

  return out_image

2 loop implementation:

def convolve2loops(image, kernel):
  kernel = np.flip(kernel)
  pad_1 = kernel.shape[0] // 2
  pad_2 = kernel.shape[1] // 2
  image_x = image.shape[0]
  image_y = image.shape[1]

  image = np.pad(image, ((pad_1,pad_1), (pad_2,pad_2)))

  out_image = np.zeros((image_x, image_y))

  for ix in range(image_x):
    for iy in range(image_y):
      crop = image[ix:ix + kernel.shape[0], iy:iy + kernel.shape[1]]
      out_image[ix][iy] = np.sum(crop * kernel)

  return out_image
I compared my functions with scipy.signal.convolve2d on a picture of my face, using the 9x9 box filter. The scipy function adds the padding to the final image, resulting in a final image with size 383x508 from an original image of size 375x500, as opposed to my two functions, which add padding to the image before convolution, but produce a final image with the same size as the original image, and thus both output a final image with size 375x500. Otherwise, my functions and the scipy function seem to produce the same image. To complete the convolution, the 4 loop function takes around 19 seconds, the 2 loop function takes about 2 seconds, and the scipy function takes about 1 second.
The 2 loop function is at least on the same magnitude as the scipy function in terms of runtime (at least for this image), but the 4 loop function is obviously much slower.
